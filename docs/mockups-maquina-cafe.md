# Mockups finales - Maquina de Cafe TDD

## Informacion general

**Proyecto:** Maquina de Cafe TDD  
**Integrante:** Anfeerny Martinez  
**Unidad:** VI - Usabilidad  
**Repositorio:** https://github.com/AMartinez-04/maquina-cafe-tdd

## Objetivo de los mockups

Representar como se vera y funcionara la solucion desde la perspectiva del usuario. Las pantallas mantienen una navegacion logica y son coherentes con el diseno tecnico 4+1 del proyecto.

## Pantallas incluidas

1. **Portada:** identifica el proyecto, integrante y repositorio.
2. **Mapa de navegacion:** muestra el flujo entre inicio, dashboard, servir cafe, inventario, reportes y mensajes.
3. **Pantalla de inicio:** bienvenida y acceso a las funciones principales.
4. **Dashboard:** resumen operativo de cafe, azucar y vasos.
5. **Servir cafe:** formulario para seleccionar vaso pequeno, mediano o grande y cantidad de azucar.
6. **Inventario CRUD:** pantalla para consultar, registrar, editar y eliminar insumos.
7. **Reportes:** consulta de servicios realizados y consumo de insumos.
8. **Mensajes:** confirmaciones y errores importantes del sistema.
